이 사이트를 만든 이유

스포츠 산업에서 생긴 의문을 직접 정의하고, 공개자료와 코드로 확인해보는 과정을 기록합니다.

사이트 이름

‘체대생의 스포츠 바이브코딩’을 짧은 브랜드명으로 사용하고, 전체 문장인 ‘바이브코딩으로 스포츠 산업을 바라보고 분석하는 체대생’을 사이트 설명으로 사용했습니다. 길이는 줄이되 처음 보는 사람도 무엇을 하는 사이트인지 알 수 있게 하기 위해서입니다.

글을 쓰는 기준

① 질문부터 시작코드를 먼저 만들기보다 스포츠 산업에서 실제로 궁금했던 문제를 먼저 정합니다.
② 공개자료의 범위 안에서구할 수 없는 데이터를 있는 것처럼 만들지 않고, 무엇을 확보했는지 먼저 밝힙니다.
③ 가정은 숨기지 않기14개 좌석 구역, 시야각처럼 분석자가 정한 기준은 결과와 분리해 설명합니다.
④ 결과보다 과정까지어떤 수정이 있었고 바이브코딩이 어디서 도움이 됐는지 함께 기록합니다.

칼럼에 있으면 좋은 기능

현재 사이트에는 칼럼 목록, 주제 태그, 읽기 페이지, 공유 버튼, 댓글 영역을 구성했습니다. 앞으로 글이 늘어나면 검색·카테고리 필터, 시리즈 묶음, 업데이트 이력, RSS/이메일 구독을 붙이기 좋은 구조로 만들어두었습니다.

댓글에 대해

댓글은 정적 HTML만으로는 방문자끼리 공유할 수 없기 때문에 별도의 저장 공간이 필요합니다. 이 사이트에는 Giscus를 연결할 수 있도록 코드를 넣어두었습니다. GitHub Pages로 배포한다면 무료로 GitHub Discussions를 댓글 저장소처럼 활용할 수 있고, 칼럼 URL별로 댓글이 자동 분리됩니다.
